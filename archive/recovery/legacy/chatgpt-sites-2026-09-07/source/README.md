# 学序 · 个人学习工作台

为单个用户管理线性代数、概率统计、日语与摄影。支持电脑和手机浏览器，使用 Sites 私有访问、D1 记录与 R2 文件保存。

## 使用顺序

1. 偏好与 AI 设置：填入 DeepSeek API Key，验证并连接，月预算默认100元。
2. 时间安排：编辑作息、保留时间与休息日，CSV课表可稍后导入。列名可映射；开始结束时间使用 HH:mm。
3. 资料库：导入 PDF/PPTX/DOCX/TXT/MD，或添加课程链接和字幕/目录。
4. 学习路线：编辑四科目标、水平、考试日期，生成并选择两到三套方案中的一套。
5. 今日学习：生成每日任务，学习后提交短测和反馈。
6. 时间变化：调整当天额度或提前报备；未完成任务说明原因后重排。

没有真实资料时可先使用明确标注的示例练习。结束体验会清除示例，示例不进入正式统计。

## 运行与检查

- npm install
- npm run dev
- npm run db:generate
- node scripts/test.mjs
- npx tsc --noEmit
- npm run build

数据库结构由 db/schema.ts 和 Drizzle 迁移管理。不得在生产运行时重复建表。
正式部署所需逻辑绑定为 DB 和 FILES。STUDY_ENCRYPTION_KEY 为32字节密钥的Base64表示，托管环境以secret配置；本地放入忽略提交的.dev.vars。API Key通过AES-GCM加密存储于D1，不会返回客户端。

## AI 及材料处理

调用官方 DeepSeek Chat Completions 接口，可选择 V4 Flash/Pro。预算依据2026-09-07官网输入、缓存和输出单价估算，超时保留费用上限以避免继续超额；账单以DeepSeek为准。正式调用需要用户自己的有效密钥。接入结构已实现，交付时没有用户密钥，因此未进行真实付费模型调用。

文件在浏览器提取文字后保存原文件与文本。单文件20MB；PDF最多提取500页、约80万字符；扫描PDF需另补文字，不含OCR。PPTX/DOCX读取主要文字，不包含图表视觉理解。较长资料按目标和最近任务选取片段，必要时按章节拆分上传。

视频链接可保存和打开，不自动读取全部视频。需提供目录、正文或字幕才能准确定位。资源建议使用精选官网入口及用户导入的材料，不提供无限制全网自动搜索。具体页码/时间需要正文引用依据，否则拒绝该次生成。

短测是辅助判断，统计展示任务完成和验证结果，不代表完整学科掌握比例。未通过时安排巩固练习，后续结果继续留存。

## 数据与并发

保存使用版本号进行并发检查，避免电脑手机互相覆盖。每用户AI调用串行锁及预算预留用于限制重复请求。服务端检查身份、同源请求、输入类型、资源引用与模型输出格式。
