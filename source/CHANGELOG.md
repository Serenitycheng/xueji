# 版本记录

## 0.4.0 — 2026-09-14

- 新增开发领域，按《开发学习方案 ver2》内置可选路线，Python 与工具同步起步，系统学习与项目实践并行；原 PDF 登录后可查看，全文不自动发送给 DeepSeek。
- 领域接入路线、资料归属、任务、反馈、进度和云端版本比较，布局按实际领域数量适配。
- 旧账户、离线缓存和历史恢复补齐缺少的开发领域；已有目标和记录不重置。
- 写入协议提升到 4，新增 0004 前向迁移，发布时同步更新本机资料处理器。

## 0.3.0 — 2026-09-08

- 资料库支持直接拖入文件，所属学科继承当前筛选。
- 本机免费 OCR 与 Codex 订阅分析接力，结果经版本检查同步到网站；展示目录、页码与起步任务。
- 方案调整区分实际换资源、改变学习步骤、缩短任务和按教材重整顺序；保留比较基准及已选路线。
- 每周可视化课表，统一小学期周次、真实日期与学习时间计算。
- 写入协议提升到 3，增加资料队列和正文修改冲突保护。

## 0.2.3 — 2026-09-07

- 真实调用验证后补充路线检查：拒绝编排未经核验的编号课时及固定完成周次，使用阶段与进阶条件。
- 方案检查失败时最多请求一次修正；修正仍失败则保留旧内容，费用继续计入同一月度预算。

## 0.2.2 — 2026-09-07

- 资料导入和链接弹窗继承当前筛选学科；全部资料下要求主动选择，不再默认线代。
- 资料详情支持修改学科，保存进入同一云端同步和版本历史流程。
- 增加 MARUGOTO、艾琳基础短剧和动漫日语等已核验入口，明确主课程与辅助练习。
- 日语对比路线校验主课程来源，不允许把同套教材及配套网站包装成不同路线；所有方案匹配用户当前基础。
- 推荐区域说明 DeepSeek 使用精选资源与已导入资料，当前没有实时全网检索。

## 0.2.1 — 2026-09-07

- 单文件上限提高至 200MB；前端、登记接口和私有直传令牌共用同一限制。
- 先上传原件再选取参考文字，30MB 以上默认仅保存原件；提取失败保留文件。
- 原件大小和 AI 参考文字数量分开限制，TXT/MD 仅读取需要的片段；PDF 提取设置超时清理。

## 0.2.0 — 2026-09-07

- 写入协议与内容版本分别校验；数据库拒绝旧程序写入和并发覆盖。
- 保存编号防止网络重试重复写入或再次调用 AI；超时请求可停止，迟到结果不能覆盖内容。
- 已点击保存的修改先写入本机 IndexedDB，断网与刷新后保留。冲突必须比较并明确选择后处理。
- 页面可见时每 15 秒、重新联网及切回页面时同步；编辑中的表单保留原值。
- 每次成功修改留存内容历史；历史恢复创建新版本。资料正文使用不可覆盖的独立存储路径。
- 新增“同步与版本”，支持查看、比较、恢复和导出内容历史；密码、API Key 和账单不在内容备份中。

## 0.1.0 — 2026-09-07

- 迁移至 Vercel，使用个人密码登录、Neon 数据库和私有 Blob 文件存储。
- DeepSeek 加密连接，四科学习规划、课表、资料和反馈。

## 发布和回退约定

Git 标签 `app/v版本号` 固定每次发布的代码；`APP_VERSION` 与 package.json 同步更新。
数据版本 `DATA_VERSION` 描述内容结构；不兼容写入须提升 `WRITE_PROTOCOL` 并增加前向迁移，不能重置学习记录。
生产数据库迁移仅向前运行，代码回退只能选择兼容当前数据结构和写入协议的版本。
0.1.0 的旧写入会被 0.2.0 的数据库保护阻止，不能直接回退到 0.1.0 继续保存。
发布不执行数据种子或覆盖用户配置。内容恢复通过历史界面完成，与代码回退相互独立。

0.3.0 使用协议3，0.2.x旧代码仍可读取兼容内容，但不能直接回退继续写入。
