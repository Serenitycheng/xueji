# 学序 · Vercel 版

管理线性代数、概率统计、日语、摄影和开发的个人学习工作台。电脑与手机浏览器共用同一份云端记录。DeepSeek 负责路线方案、任务和简短建议，完成与验证结果分别记录。

## 使用

1. 用本机设置页中创建的个人访问密码登录。
2. 在「偏好与 AI 设置」连接或更新 DeepSeek API Key，月预算默认100元。
3. 在「时间安排」导入CSV课表、映射列名并设置作息；课程开始和结束使用 HH:mm。
4. 在「资料库」导入教材、课件或添加课程链接。单文件最多200MB，原文件保存在私有存储。
5. 设置各学习领域的目标、基础与考试日期，生成并选择路线，然后安排每日任务。
6. 完成任务后填写反馈与简短验证；临时有事可调整当天学习额度。

## 开发学习

开发领域以打牢基础为先，现阶段侧重 AI 辅助开发（vibe coding），边做项目边系统学习。已按《开发学习方案 ver2》整理一条可直接选择的路线：Python 基础与工具同步起步，依次学习运行原理、数据结构、网络接口、数据库和软件工程；AI 拓展区分概念了解和后续实践。每个主题以自己的解释、能说明的实现、改变条件后的验证作为学习依据。

16 页原件随应用保存在 `learning-plans/development-ver2.pdf`，通过登录保护的 `/api/development-plan` 查阅。应用不会把这份原件全文自动发送给 DeepSeek；用户主动生成或调整计划时仍会使用学习目标、路线摘要及所选课程信息。其他文档、课程链接可在资料库归到“开发”。默认路线需用户选择后才使用。

0.4.0 读取旧账户和历史内容时会补齐缺少的开发领域，原有目标、课表、资料和学习记录保持原值；后续正常保存时进入内容历史。已有开发目标不会被默认值覆盖。发布需先运行包含 0004 的前向迁移，再使用新版网站与本机处理器；协议 3 的旧页面不能继续写入。

## 运行

需要 Node.js 22.13+。执行 `npm install`，参考 `.env.example` 配置以下服务端变量：

- `DATABASE_URL`：Neon PostgreSQL连接地址。
- `BLOB_READ_WRITE_TOKEN`：Vercel私有Blob存储凭据。
- `STUDY_ENCRYPTION_KEY`：32字节随机密钥的Base64表示。
- `SESSION_SECRET`：至少32字符的随机会话密钥。
- `STUDY_PASSWORD_HASH`：`salt:hash`，salt为随机16字节的hex，hash为Node scrypt(password,salt,64)的hex。

变量不得使用 `NEXT_PUBLIC_` 前缀，不应提交到版本库。API Key使用AES-GCM加密后存储在数据库，不会返回客户端。密码只存储加盐哈希。更换密码哈希会使原登录会话失效。

数据库通过 `db/vercel-schema.ts` 与 `drizzle-vercel/` 管理。先运行 `npm run db:migrate`，再运行 `npm run dev`。生产使用 `npm run build` 与 `npm start`。修改结构后运行 `npm run db:generate` 并审核迁移。

通过 Git 发布时，将现有 Vercel 项目关联到仓库，Root Directory 设为 `source`，Production Branch 设为 `main`。`vercel.json` 指定的发布脚本先检查正式环境变量、准备资源并完成 Next.js 构建，再仅在 `VERCEL_ENV=production` 时执行待应用的前向迁移；预览与本地构建不迁移数据库。任一步骤失败都会终止本次发布。协议迁移到新版正式生效之间，旧网站写入可能短暂被拒绝，草稿会保留。若迁移完成后平台发布失败，应继续完成新版发布，不能直接回退为旧协议写入程序。

也可先 `vercel link` 关联正确团队与项目，配置生产环境变量，再执行 `vercel --prod`。Vercel配置使用私有Blob直传，较大的教材不会经过普通函数请求体。学习记录使用版本号检查，避免不同设备互相覆盖。

`node scripts/test.mjs` 检查课表、任务重排、反馈去重与材料引用；`npx tsc --noEmit` 和 `npm run build` 检查类型与构建。

## 当前范围

- 支持PDF、PPTX、DOCX、TXT、Markdown和课程链接。文件导入后进入电脑处理队列，扫描 PDF 使用本机免费 OCR，Codex 通过 ChatGPT 订阅整理内容，DeepSeek 使用结果规划。最多处理5000页及80万字符，超出时保留原件并要求拆分，不静默截断。公式、图片和复杂图表仍需核对原件。
- 视频链接不会自动获取全部视频正文；补充目录或字幕后可更准确地定位。
- 资料内容作为参考数据处理，不能覆盖规划指令。具体页码、视频时间需要可核对的正文依据。
- AI调用费用按返回用量及已知单价估算，超时预留费用上限，实际扣费以DeepSeek账单为准。
- 短测用于辅助判断，不等同于完整学科掌握比例。
- 第一版仅供个人使用，无公开注册；访问密码需妥善保存。忘记密码时在Vercel更新密码哈希。

原Sites版本保留在独立工作目录中；本目录为Vercel迁移版本。

## 同步、历史与版本

“同步与版本”展示云端内容版本和软件版本。页面可见时每 15 秒同步，重新联网和回到页面时也会检查。已打开页面在断网时保留缓存和已点击保存的草稿；尚未提供完全离线启动的 PWA。未点击保存的表单文字不属于持久草稿。

每次成功修改在同一数据库事务中留存历史与保存回执。恢复历史会创建新版本；资料正文以独立路径留存，原文件不删除。JSON 导出只包含学习状态和资料索引，不包含私有原文件、资料全文、密码或 API Key。AI 调用账单与密钥单独保存，不随内容恢复。

发生冲突时，先比较最新云端和本机草稿，明确确认后再提交，不能自动用整个本机快照覆盖。普通网络失败使用原编号重试；超过 4 分钟未确认的请求允许停止，迟到写入会被事务锁检查拒绝。本机草稿不保存 API Key。

参考 CHANGELOG.md 的发布和回退约定。`node scripts/test-protection.mjs` 在随机临时 schema 验证数据库保护并清理测试命名空间。`node scripts/test-browser.mjs` 使用 Playwright 和本地 4173 服务验证前端，数据 API 全部为隔离夹具；可用 STUDY_PLAYWRIGHT 指定 Playwright 模块位置。

本机处理器、日常学习步骤与当前边界见 [资料处理与学习流程](docs/learning-flow-030.md)。
