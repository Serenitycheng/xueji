# 资料处理与学习流程 · 0.3.0

网站：https://xuexu-study-sereni1.vercel.app

0.4.0 发布说明：请使用同版本本机处理器，保存协议现为 4；下文验证记录保留 0.3.0 时的结果。新电脑需自行配置本机环境与启动方式，仓库恢复不会自动安装启动项。

## 日常使用

1. 在资料库选学科，直接拖入文件。手机可点“导入文件”。单文件最多 200MB。
2. 文件进入个人电脑处理队列。电脑上的处理程序提取正文，扫描 PDF 使用 Windows 免费 OCR；Codex 通过本机 ChatGPT 登录整理目录、页码、内容先修关系和一个起步任务。
3. 资料详情展示整理结果，章节可打开原 PDF 对应页。识别文字保存到私有云存储，电脑和手机可继续查看。
4. 课内路线直接使用已核对的教材目录，比较教材独学与不同辅助资源；DeepSeek 使用目录和正文片段安排每日任务。比较后选一套，点击“安排下一步”，再按任务学习与验证。
5. 想换方案时明确选择换资料、调整每次学习步骤、减少每次时长，或按新教材重整顺序。变化会单独列出；旧路线和完成记录保留。
6. 时间安排按真实日期展示每周课程；小学期 -3/-2/-1 对应第 1/2/3 周，常规第 1 周对应第 4 周。

## 本机处理程序

需要 Windows、Node.js 22.13+、已登录 ChatGPT 的 Codex CLI，以及 Windows 中文 OCR 语言包。

本机环境文件保留网站的 SESSION_SECRET、STUDY_PASSWORD_HASH；它们只用于访问自己的学习空间。可在忽略提交的 .env.device.local 配置 STUDY_SITE_URL、STUDY_HTTPS_PROXY、STUDY_CODEX_BIN。不要把 ChatGPT 登录凭据、环境文件或本机工作目录上传到网站或提交到 Git。

- 检查连接：node scripts/study-device.mjs --check
- 处理当前队列后退出：node scripts/study-device.mjs --once
- 持续等待新资料：node scripts/study-device.mjs

处理程序本身不依赖 Codex 桌面窗口保持打开，但需要电脑在线、Codex CLI 仍处于登录状态。它先检查队列信号，只在有新文件时调用模型。文字和分析缓存位于 work/device；中断后复用已识别页面与已有分析结果。暂停的任务在网站点击“继续处理”重试，避免异常时反复消耗额度。

本地 OCR 没有模型调用费用；分析使用 ChatGPT 订阅中的 Codex 额度；DeepSeek 的学习规划费用独立计算。订阅不是网站可直接调用的通用 API，资料由个人电脑作为中间处理端。

## 保护与边界

- 处理器领取任务后定时报告进度，同一任务由一个有效处理者写回。
- 保存分析必须同时匹配内容版本、任务编号及处理开始时的正文路径。手动编辑、删除或恢复历史后，旧结果不能覆盖新内容。
- 正文以新路径保存；学习状态沿用云端历史、保存回执和旧版本写入保护，写入协议为 3。
- 当前扫描工具对矩阵排列、上下标、公式、图表等不可靠；资料会保留这项说明。不能用残缺 OCR 公式直接出计算题。
- Codex 整理使用目录和逐页页首索引，并不宣称精读所有证明。DeepSeek 根据当前学习需要选取正文片段，具体引用须有原文依据。
- 真实的考试范围、课堂当前进度、已有基础通常不在教材里，仍需用户提供。视频链接暂不自动获取完整字幕。
- 推荐入口目前为人工核验的资源库，没有实时全网搜索；无新资源时会明确说明，并停止本次 AI 请求。短测仅用于辅助判断掌握程度。

两本实际教材完成全部页面文字提取：线代 271 页、概率统计 712 页，其中本地扫描识别分别为 270 页与 110 页。Codex 订阅分析已实际运行，线代整理为 30 个单元、概率统计为 10 章。扫描数学公式保留原页核对提示。

24 项自动检查覆盖时间预算、真实周次与调课、路线资源身份、资料页码有效性、正文覆盖保护等；另已通过数据库隔离保护检查和桌面/手机浏览器检查。生产回写使用网站标准保存协议，没有直接替换整份用户状态。

本机已创建当前 Windows 用户的启动项「Studyflow 资料处理」，登录电脑后自动启动。可在 Windows 启动应用中禁用，或删除对应 Startup 快捷方式。重新手动启动可使用 outputs 中的「启动资料处理」快捷方式。
