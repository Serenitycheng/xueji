## 记录进度

1. 在“选择当前学习小节”中直接选择已学到的位置，或在展开的小节内点击“设为当前小节”。
2. 页面上方显示这一节的学习指引和资料位置。
3. 点击“记录这一节”，填写本次停点、卡点或下一步。记录关联到具体小节。
4. 刷新或下次登录会保留位置；切换到其他小节后，原小节的记录和掌握判断仍保留。

选择小节只记录位置，不自动增加已接触、掌握或完成状态。已保存的下一步不会因切换小节被覆盖；来自另一单元的下一步会显示所属位置。“复制学习行动”同时包含当前路线位置及资料入口。

## 教材和资源定位

- 数学主教材使用现有资料 ID 和登录保护的附件接口，链接附带 `#page=` PDF 页序。浏览器不支持页码跳转时，按页面显示的 PDF 页序手动定位。
- 开发入门以用户提供的Python第3版教材为主，前9节已映射这份416页PDF的页序；资料库导入对应PDF后自动连接私有教材。开发方案原件继续保留独立入口。
- 专业 05 的 Elliott 第 21 版目前只核到章级，正文页码待取得该版电子书后补齐；现有 OpenTuition FA 视频已细分到课节。
- 日语以册、课、栏目和已核练习号定位，未核实的音轨号与正文页码不填猜测值。
- 资料库缺少对应数学原件时显示提示；不把别的账号的文件或不匹配的教材替代进去。

## 数据兼容

路线正文随应用发布，数据保存在 `lib/curricula/six-directions.json`。读取学习空间时为既有方向关联路线，补充缺少的方向。关联优先使用稳定的旧方向 ID，其次使用已有的明确方向名称。

旧方向 ID、名称、暂停状态、目标、当前内容、下一步、学习记录、附件和手动单元保留。每个路线节点/小节在首次选择时才建立进度单元，使用稳定编号；重复读取或重新选择不产生重复单元。未展开的专业节点也可以保存节点级位置。

概率论路线现在只到“1.5”这一节。旧细分小节编号仍能定位到所属节，原有单元、学习记录、掌握判断和下一步不做合并或删除。按整节继续学习时建立整节进度，旧小节的掌握判断不自动升级为整节掌握。整节条目显示新旧记录总数；原本已是节级的进度继续沿用。其他五个方向的目录层级和课节编号不变。

选择小节使用现有保存事务、版本检查和回执机制。重试不会重复创建单元，旧版本冲突不会覆盖较新的学习位置。数据外壳版本保持 1，写入协议保持 5，无新增数据库迁移。
