# 学序重构交付说明ver1

本轮按《学序功能重构说明ver1》实施 P0，应用版本 0.5.0。修改的是现有学序项目，未建立新产品。P1 的 AI 建议、P2 的跨工具同步没有在本轮启用。

## 已实现的使用流程

1. **新建方向**：在“学习方向”输入名称即可建立。可选择课程、技能或阅读与探索，阶段目标和材料允许以后补充。
2. **继续学习**：首页显示活跃方向的当前单元、最近实际停点、卡点和已确认下一步；置顶方向和本机上次进入的方向优先。点击继续即可进入该方向。
3. **结束记录**：填写结果、当前判断、下一步中的必要内容即可保存。接触状态与掌握判断独立；“看过但没检验”不会变成掌握。卡点、依据和位置在展开项中。不填新下一步会保留原有内容，并明确标记尚未更新；也能明确留空。
4. **暂停与恢复**：方向详情底部可以暂停、恢复、归档或确认完成。记录、材料与下一步继续保留，不生成中断期间的欠账。
5. **复制到序流**：点击“复制学习行动”得到标题、动作、开始位置、结束条件、方向地址和相关入口。只报告复制结果，没有调用序流或创建外部任务。

支持单元添加、编辑、排序和设置当前内容；同名单元不合并，排序不改变身份。规则建议须先查看和确认，不覆盖用户保存的下一步。最近一次记录可以修正，原记录及修正关系继续保留；已有后续记录或已切换单元时，用新的记录说明修正。

### 映射方式

- 旧课程 ID 直接作为学习方向 ID，保留名称、阶段目标及暂停状态，并标明来源于旧档案。
- 仅对用户已经选择的旧路线，将其阶段文本转换为有稳定 ID 的单元。没有可靠起点时不指定当前单元，也不生成正式下一步。
- 旧任务、完成情况、分数、时长、考试信息、课表、临时调整、旧方案、日志和材料索引保持原字段；不转换成独立完成或已掌握。无法可靠关联的任务进入待关联历史入口。
- 新账户使用空方向列表，不写入演示任务。对 0.4.0 之前旧档案的开发领域补齐保持既有兼容方式，并明确旧档案来源；新账户不会因此自动增加学习领域。
- 兼容转换在读取时进行，下一次成功写入时随事务保存；重复读取或迁移不会重复生成方向或单元。未知旧字段继续保留。
- 沿用数据外壳版本 1，`learning.version` 为 1，应用写入协议升至 5。新增 `0005_learning_workspace.sql` 仅更新写入保护，没有删表、清空数据或改动附件标识。
- 数据库内容历史和回执仍在同一事务内写入。发生新写入后，禁止直接还原旧数据库备份覆盖新记录；应先保护新内容，再使用兼容版本或经比较的内容恢复。

### 实际核对结果

- 迁移夹具中的全部旧字段前后深度一致；包含旧任务和附件索引，重复转换与持久化后结果一致。
- 使用 PGlite 执行实际 SQL 迁移、事务、应用 GET/POST、历史与资料接口。验证了原附件 ID 经当前账户检查后取回相同测试文件字节，匿名和未知 ID 被拒绝。
- 生产附件下载、最新真实记录数量、真实设备处理队列与生产数据库迁移均未测试。夹具结果不等于生产迁移已完成。
